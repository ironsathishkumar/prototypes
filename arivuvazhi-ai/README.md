# ArivuVazhi — clickable prototype

## Run
Open `index.html` in a modern browser; nothing to install. Best viewed as a phone-sized UI.

## Included
- Welcome, sign-in preview, and onboarding for App Language, Exam/Study Language, active program, goal, initial assessment, learning profile, and sample plan
- Home dashboard with active-program context, preparation progress, next learning action, and links to study tools
- Learn syllabus overview, topic progress, illustrative material, and sample notes
- Practice setup with Easy, Medium, Hard, and Very Hard modes, a sample question, and immediate explanation
- Sample mistake book and revision queue
- Separate focused subject/topic mock and full mock flows, including instructions, question view, mark-for-review preview, submission confirmation, and sample results
- AI Tutor example, study planner, and active-program-scoped progress insights
- Profile, language and theme preferences, program switching, help, and dedicated optional feedback
- Phone-frame layout, light/dark system palettes, and anchor-based navigation without JavaScript

## Limitations
Sample data only; nothing is connected or saved. Authentication, timers, answer selection, scoring, and feedback submission are not functional. Program availability, exam rules, questions, language coverage, scores, and Tutor responses are illustrative and do not confirm approved content. Full mock rules must come from the active program’s configured exam settings; exact focused-mock settings are not specified. Inactive-program progress retention, detailed planner behavior, and feedback handling workflows remain undecided. This is an HTML/CSS phone mockup.
